# Changelog

## 0.1.0

- Сервер запускается из расширения автоматически, если он не отвечает.
- Настройки `xboctLog.autoStart`, `xboctLog.serverPath`, `xboctLog.dataDir`.
- Команда `Xboct Log: Start Server`.
- Страница недоступного сервера: запуск, повторная проверка, настройки, ссылка
  на релизы.

## 0.0.4

- Первая версия: борд во вкладке редактора, тема, горячие клавиши переключения
  вкладок.
