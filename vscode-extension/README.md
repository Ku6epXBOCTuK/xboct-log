# Xboct Log для VS Code

Тонкий клиент: открывает борд `xboct-log` во вкладке области редактора.

Сервер запускается отдельно — служба `xboct-log` на `http://127.0.0.1:45881`.

## Команды

- `Xboct Log: Open Board`
- `Xboct Log: Reload`

## Настройки

- `xboctLog.serverUrl` — адрес задеплоенного приложения.

## Сборка

```sh
npm install
npm run compile
npm run package
```
