# Xboct Log для VS Code

Открывает борд `xboct-log` во вкладке области редактора и сам запускает
локальный сервер, если он не отвечает.

## Установка сервера

Нужен один из вариантов:

- установщик `xboct-log-<version>-win-x64-setup.exe` из
  [релизов](https://github.com/Ku6epXBOCTuK/xboct-log/releases);
- `npm install -g xboct-log`.

Расширение ищет `xboct-log` по пути из настройки `xboctLog.serverPath`, затем в
`%LOCALAPPDATA%\Programs\Xboct Log`, затем в `PATH`.

## Команды

- `Xboct Log: Open Board`
- `Xboct Log: Start Server`
- `Xboct Log: Reload`

## Настройки

- `xboctLog.serverUrl` — адрес приложения, по умолчанию
  `http://127.0.0.1:45881`.
- `xboctLog.autoStart` — запускать сервер при открытии борда, по умолчанию
  включено.
- `xboctLog.serverPath` — путь к `xboct-log.cmd` или команда запуска.
- `xboctLog.dataDir` — папка данных для запускаемого сервера.

## Копирование картинок

Кнопка копирования есть у превью вложения в списке и в окне просмотра. Работает
она через системный буфер, а не через браузерный `navigator.clipboard`: вебвью
VS Code выдаёт clipboard-разрешения только своим фреймам, а борд открыт из
`http://127.0.0.1`, поэтому запись изображения из страницы недоступна, а
копирование выделенного `<img>` кладёт в буфер только HTML без самой картинки.
Поэтому картинку в PNG готовит страница, а в буфер её кладёт extension host.

Что это значит на практике:

- **Windows** — при активации расширения поднимается один фоновый
  `powershell.exe` с уже загруженными `System.Windows.Forms` и `System.Drawing`.
  Первое копирование после старта занимает около 30 мс, последующие — 3–4 мс.
  Процесс виден в диспетчере задач как `powershell.exe` от VS Code и живёт до
  закрытия окна или деактивации расширения; если он упадёт, следующий клик
  поднимет новый. Если хелпер не стартовал, используется разовый запуск
  PowerShell — он заметно медленнее.
- **macOS и Linux** — на каждое копирование запускается `osascript` либо
  `wl-copy`/`xclip`, это дольше. На Linux нужен `wl-clipboard` (Wayland) или
  `xclip` (X11) в `PATH`.
- Если ни один способ не сработал, кнопка показывает крестик и открывает
  картинку во внешнем браузере — там работает обычный правый клик «Копировать
  изображение».
- Копия всегда в PNG: прозрачность сохраняется, анимированный GIF становится
  статичным кадром.
- Пока идёт копирование, кнопка показывает спиннер и не реагирует на повторные
  клики.
